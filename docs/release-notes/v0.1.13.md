# YoloForge 0.1.13

- Test-Repositories übernehmen keine maschinenweiten Git-Filter mehr. Dadurch
  läuft die Checkpoint-Übergabeprüfung auf den GitHub-Runnern reproduzierbar,
  während die Produktionsprüfung unsichere Checkout-Filter weiterhin ablehnt.
- Der native Build kann nun vor dem Anlegen eines Release-Tags manuell für
  Linux, macOS und Windows gestartet werden.
