# YoloForge v0.1.17

- Die Desktop-GUI stellt die zuletzt bestätigte Factory-Verbindung beim Start wieder her. Das Token bleibt separat gespeichert.
- „Ergebnis vorhanden“ setzt eine bestätigte Übernahme auf dem Zielbranch voraus. Die Overview unterscheidet blockierte Übernahmen, fehlgeschlagene Ausführungen und automatische Wiederholungen.
- Der Merger bearbeitet echte Git-Konflikte in einem separaten Worktree. Reviewer und Merger haben eigene Listen, Archive und Modellauswahl in den Factory- und Projekt-Settings.
- Alte, manuell integrierte Ergebnisse können gezielt nachgetragen werden. Der Release allein ändert keine bestehenden Ticketstände. Siehe [Übernahme und Nachtrag](../result-publication.md).
- Enthält Directs und Korrekturen für Prompt-Eingabe, Zwischenablage, Inline-Antworten, Benachrichtigungen und Runner-Anzeigen.
