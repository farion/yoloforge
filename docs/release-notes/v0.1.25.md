# YoloForge v0.1.25

- Nach einer Reviewer-Freigabe übernimmt der Runner den vorbereiteten Snapshot auch dann, wenn im Projektprofil kein Modell eingetragen ist. Die Übernahme ist ein Git-Schritt und benötigt kein Modell.
- Bereits freigegebene Intents, die deswegen in „In Validierung“ hängen, werden nach dem Server-Update beim nächsten Scheduler-Durchlauf weiterverarbeitet. Die Implementierung muss nicht erneut gestartet werden.
