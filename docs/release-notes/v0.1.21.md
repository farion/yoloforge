# YoloForge v0.1.21

- Die Inbox bündelt offene Fragen und eskalierte Intent-Probleme. Routine-Erfolge und interne Wiederholungen erzeugen keine Toasts.
- Der Orchestrator kann fehlgeschlagene, archivierte Intents einmal in derselben Session fortsetzen, freigegebene Standardfragen beantworten und um Zustimmung zu konkreten Lösungsvorschlägen bitten.
- „Zurück zum Entwurf“ bewahrt Prompt und Anhänge und wartet auf die bestätigte Entfernung der alten Session und ihres Worktrees durch den zuständigen verwalteten Runner.
- Fehlgeschlagene Orchestrator-Läufe wandern nach einer Stunde oder auf Anforderung ins Archiv. Nicht unterstützte Funktionen bleiben, soweit anwendbar, mit einem Kompatibilitätshinweis sichtbar.
- Die Factory weist den Reviewer auf veröffentlichte Ergebnisse ohne Git-Dateiänderungen hin. Für dauerhaft ungeeignete feste Session-Zuordnungen bietet die Inbox eine Neuzuordnung an.
- Die Session-Ansicht bündelt manuelle und automatische Sessions. Die Infrastruktur- und Projektaktivitätsansichten wurden überarbeitet.
- Modellzugänge unterscheiden den kostenlosen OpenCode-Katalog und die kostenpflichtige OpenCode Console.

Server, Runner und Desktop gemeinsam aktualisieren. Das Release veröffentlicht Pakete; die Installation auf dem Server erfolgt wie bisher über Betreiber-Ansible.
