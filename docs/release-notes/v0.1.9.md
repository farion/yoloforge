# YoloForge 0.1.9

- Die Desktop-Pakete für Linux, macOS (Apple Silicon) und Windows enthalten
  Server, Runner und OpenCode. **Lokale Factory** braucht keine separate
  Installation und keinen OpenCode-Download zur Laufzeit.
- Die GUI merkt sich die zuletzt erfolgreich verbundene Factory. Das
  Zugangstoken bleibt in einer privaten Datei, getrennt von den Einstellungen.
- Die Infrastrukturansicht kennzeichnet Internetverbindungen mit einer
  Weltkugel und führt Runner-Verbindungen auf getrennten Linien.
- OpenCode-Formulare warten auf Benutzereingaben. Die automatische
  Fragenorchestrierung beschränkt sich auf Berechtigungsanfragen.
